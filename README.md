# PCE Gruppe Social Hub

Static GitHub Pages landing page for the three PCE companies.

- Matte-black theme is the default; light theme remains available.
- DE / EN language selector translates the landing page and remembers the selection.
- Welcome copy is friendly and visitor-focused rather than technical.
- Header controls have a dedicated top row so DE/EN and theme controls do not overlap the welcome label.
- Responsive layout for mobile and desktop.
- Company favicons are used in the company cards.

## Run locally
```bash
python3 -m http.server 8000
```
Open http://localhost:8000. No build step is required.
